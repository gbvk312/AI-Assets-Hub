01. Single-File Manifest Schema (plugins.json)

Every card, install snippet, and documentation modal in ForgeHub is generated directly from objects in plugins.json. Contributors add plugins by appending an object with these eleven required properties.

Field Type Constraint Description
id string Unique slug (kebab-case) Unique identifier used for deep-linking and DOM actions (e.g. gh-release-sentinel).
name string Required Human-readable title displayed on the plugin card and documentation header.
description string 80–180 chars recommended Concise summary indexed by the real-time search engine.
author string GitHub username Maintainer handle credited on the card metadata bar.
version string SemVer (X.Y.Z) Semantic version string rendered with tabular numerals.
stars number Non-negative integer (>= 0) Community popularity count rendered with tabular numerals and used when sorting by Most Stars.
category string Automation | UI | CLI | API Primary taxonomy bucket mapped to the top category filter bar.
tags string[] 1–5 lowercase strings Searchable and clickable keywords for cross-category filtering.
installCommand string Required CLI command, CDN script tag, or package snippet copied via One-Click Copy.
downloadUrl string HTTPS URL Direct link to the release tarball, ESM bundle, or GitHub release asset.
readme string Markdown string Full usage documentation and code examples rendered inside the View Source / Docs modal.

02. Zero-Build GitHub Pages Deployment Architecture

Commit index.html, app.js, and plugins.json to the root of any GitHub repository and enable GitHub Pages from the main branch.

File 01 · index.html

Declarative Shell & Modals

Loads Tailwind CSS and Lucide Icons via CDN, defines semantic accessible dialogs for documentation and contributor onboarding, and requires zero bundler compilation.

File 02 · app.js

Vanilla ES6+ Runtime Engine

Fetches ./plugins.json dynamically, manages reactive search and category filtering, handles Clipboard API copying with toast feedback, and parses Markdown readmes.

File 03 · plugins.json

Git-Backed Plugin Manifest

Single source of truth for all listings. Community contributors submit new plugins by opening a Pull Request that appends one JSON object to this file.
